# 우리의 이탈리아 · 2027

[여행 페이지](https://quokka-hunter.github.io/honeymoon/)

2027.03.26–04.09 이탈리아 신혼여행: 일정 지도, 준비 체크리스트, 경비 기록.

- `docs/data.js`: 날짜별 일정과 관광·숙박 스팟
- `docs/app.js`: 지도와 일정 화면
- `docs/planner.js`: 탭, 체크리스트, 경비 입력 및 브라우저 저장
- `docs/index.html`, `docs/style.css`: 화면 구성과 스타일

`main`의 `docs/`를 수정하면 GitHub Pages에 자동 반영됩니다.
체크리스트와 경비는 각 브라우저의 localStorage에만 저장되며 기기 간 동기화되지 않습니다.
브라우저 데이터를 삭제하면 입력 기록도 사라집니다. 입력 기록은 GitHub에 업로드되지 않습니다.
금액은 EUR/KRW별로 합산하며 환율 변환을 하지 않습니다.

로컬 실행: `python3 -m http.server 8000 --directory docs`

지도와 길찾기는 인터넷이 필요합니다. 여행 운영 정보의 출처는 페이지의 ‘여행 참고’에서 볼 수 있습니다.
지도 라이브러리와 데이터 라이선스는 `THIRD_PARTY_NOTICES.md`를 참고하세요.

## 기록 백업과 복원

상단 **기록 백업**에서 경비·체크리스트를 JSON으로 다운로드하고 다시 불러올 수 있습니다.
복원은 현재 브라우저의 두 목록 전체를 교체하므로 먼저 현재 기록을 백업하세요.
백업 파일은 GitHub에 업로드되지 않으며, 다른 기기로 파일을 전달한 후 불러올 수 있습니다. 자동 동기화는 하지 않습니다.

백업 형식: `app: "italia-honeymoon"`, `version: 1`, `exportedAt`, `tasks`, `expenses`.
금액 필드 `cents`는 통화 금액의 100배인 정수입니다(EUR 12.34 → 1234, KRW 1000 → 100000).
파일 크기, 필드 형식, 중복 ID와 금액을 확인한 뒤 복원합니다.

공개 저장소라고 다른 사람이 원본을 수정할 수 있는 것은 아닙니다. 저장소 쓰기는 소유자와 허용된 Collaborator만 가능합니다.
웹페이지의 입력은 현재 각 방문자의 브라우저 기록만 바꿉니다. 여러 기기의 공동 기록과 허용된 계정만 쓰는 기능은 별도 인증·저장 서비스가 필요합니다.

## 스프레드시트 일정표 연동

2026-09-21부터 일정표와 웹 일정은 고정 ID로 대조합니다. `docs/data.js`의 day.id, spots[].id, parking[].id는 날짜·장소·순서가 바뀌어도 유지합니다. 새 항목에는 기존과 중복되지 않는 ID를 부여합니다.

- 전체 일정: 날짜·도시·제목·부제·숙박·이동·주의사항을 day 필드와 연결합니다.
- 상세 일정: spots[].id로 시간·장소·분류·설명·팁·URL·좌표·검색어를 연결합니다. 날짜는 상위 day.id에서 가져오며, 같은 날짜의 방문 순서는 순서 열로 관리합니다.
- 주차: parking[].id로 연결하고 day.id와 순서로 배치합니다.
- 숙소 후보: docs/index.html의 여행 참고 목록과 대조합니다. 실제 숙소를 선택하면 관련 날짜의 stay와 spots도 함께 수정합니다.
- Excel의 요일·날짜 조회·장소 수·박수·지도 링크는 계산 열입니다. 계산 결과를 원본 값처럼 덮어쓰지 않습니다.

자동 동기화 서비스는 설치되어 있지 않습니다. 사용자가 변경한 최신 스프레드시트를 제공하거나 갱신을 요청하면, 기준 Git blob과 최신 GitHub 및 스프레드시트를 3자 비교하여 반영합니다. 서로 다른 필드의 변경은 합치고 같은 필드의 상충 변경은 확인 후 처리합니다. 행이 사라진 경우 삭제 의도를 확인하며, 새 항목은 ID와 연결 관계를 검증합니다. 원격 파일은 현재 SHA를 확인해 업데이트하고 기존 스프레드시트 파일의 버전을 갱신합니다.

도시·날짜·숙박 기간 변경 시 app.js의 cityStops와 index.html/README의 요약도 점검합니다. 예약번호·이름·회원번호는 공개 저장소에 올리지 않습니다. 체크리스트와 경비는 브라우저 별도 기록으로 이 일정표의 연동 범위에 포함되지 않습니다.
